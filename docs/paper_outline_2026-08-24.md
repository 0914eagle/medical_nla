# 논문 골격 — 절별 내용 배치 (2026-08-24)

## RQ 3개 (교수님 3축 = 설명/진단/교정과 1:1)

- **RQ1 (설명)**: 의료 LLM의 내부 표상을 자연어로 판독할 수 있는가 — 그
  판독을 측정 계기로 신뢰할 수 있는가?
  → 4.1: 그렇다, 검증 배터리 조건부 (스왑 0.993 · 암기 0.000 · unseen 0.75).
- **RQ2 (진단)**: 임상적 교란(소견서)이 진단을 움직일 때, 반사실 없는 단일
  실행의 내부에서 그것을 진단할 수 있는가 — 어느 케이스가, 상태의 어디서,
  왜?
  → 4.2–4.4: 움직임 실재(−23.1pp)·설명문 무예고(0.5)·내부는 드러냄(보존
  86%, 플립 국소화 ▢, 원인 서술 ▢; 폐쇄 코퍼스 탐지 최강은 프로브 0.98로
  정직 표기 — 판독의 몫은 열린 어휘와 "왜").
- **RQ3 (교정)**: 읽어낸 내부를 되먹이면 밀린 답을 고칠 수 있는가 — 무엇이
  지렛대이고 무엇이 역효과인가?
  → 4.5: 내용은 지렛대(+22.8pp), 재고 요청은 6배 증폭기(항복 45–64%), 배포
  정책은 정밀 선별과의 결합에 달림(하이브리드 ▢).

테제 한 줄: **앵커링은 내부의 소거가 아니라 출력의 사건이다 — 검증된
판독은 그것을 보고, 서술하고, 되돌리는 재료를 준다.**

## 1. Introduction

**임무**: "진단 LLM의 설명은 원인을 말하지 않는다 — 내부를 자연어로 읽으면
케이스 단위로 언제·어디서·왜 밀렸는지 보인다"까지 5문단으로 도달.

- 문단 1 — 임상 훅: 진단 오류와 인지 편향 (미국 연 4–8만 예방가능 사망,
  40–80%에 인지 편향 관여 [npj 2025]; anchoring [Croskerry]). LLM이 임상
  워크플로에 들어오는 중.
- 문단 2 — 문제: 설명은 원인을 말하지 않는다 [Turpin]. 우리 실물 훅 한 줄:
  소견서 한 문장이 정답률을 23%p 떨어뜨리는데, 어떤 CoT도 그것을 예고하지
  않는다 — 심지어 "소견서는 성급하다"고 기각을 선언한 체인조차 밀린다.
- 문단 3 — 질문과 접근: 내부 표상을 자연어로 판독(NLA)하되, **계기 검증 +
  인과 테스트베드** 위에서. 배포 상황(반사실 없음, 단일 실행)을 명시.
- 문단 4 — 기여 5개 (불릿):
  1. **검증된 계기**: 판독 신뢰의 검증 배터리 (스왑 추적 0.993, 암기 0.000,
     unseen 서술 0.75).
  2. **인과 테스트베드**: 소견서 4조건 개입 — 임상적으로 실재하는 교란,
     위약 대조, cue 위치 불변이 설계로 보장.
  3. **앵커링의 해부** (중심 기여): 원래 답은 상태에 보존되고(밀린 케이스
     86% — probe·판독·짝지음 삼중 확인), 플립은 국소화된 구간에서 일어나며
     ▢, 판독이 그 구간의 원인을 서술한다 ▢.
  4. **탐지의 정직한 지도**: 설명문 ~0.5 · 출력 기반은 침묵 부분집합에서
     구조적 장님 · 폐쇄 코퍼스에선 지도 프로브가 최강(0.98) · 판독 0.84는
     열린 어휘로 일반화되는 유일한 신호.
  5. **교정의 두 발견**: 재고 요청은 앵커링을 6배 증폭(항복률 45–64%);
     판독 *내용*은 밀린 케이스의 지렛대(r5−r4 = +22.8pp); 하이브리드 정책 ▢.
- 문단 5 — 로드맵 한 줄.

## 2. Related Work (확정 2절 — related_work 문서 §3)

- **2.1 Cognitive bias and unfaithful explanations in medical LLMs** (문제):
  Turpin 한 줄 + Croskerry → BiasMedQA·추론도 못 막음·Mahajan(트레이스 감사

## 3. Experimental Setup

**임무**: 재현 가능한 사실 서술 — 데이터 → 개입 → 계기 → 신호와 채점 →
실험 설계. 주장은 하지 않는다(주장은 Results).

- **3.1 Data**: DDXPlus [Fansi Tchango 2022] — 49병리, 감별진단 포함 합성
  ~130만. 우리 표본: 진단당 100 균형 추출(seed 17) = 4,900 → 전문의 프롬프트
  렌더링(소견 불릿 + 직답 지시) → 무소견서 직답 정답 1,747(35.7%)만 유지
  (틀리던 케이스는 '밀림'을 정의할 수 없음). 35.7%는 공개 벤치마크 구간
  (MedS-Bench 35.2/34.8; MedGemma TR·H-DDx도 DDXPlus 사용). 채점: 포함+별칭
  (H-DDx의 flat-채점 비판 인용), 판정자 2차 ▢. `gold_in_prompt` 케이스
  (가족력에 진단명 등장) 플래그 후 층화. 스케일: corpus-300 (진단당 300 =
  14,700 → 직접정답 ~5,200 예상) ▢. [확장 시: MCR — 실제 증례 14,489,
  열린 어휘 — probe가 정의 불가한 지형.]
- **3.2 개입 — 소견서 4조건**: 소견 뒤·질문 앞 한 줄 삽입. none / 위약
  ("The referring note requests evaluation.") / wrong(감별 1순위 비정답 —
  기각 불가능한 그럴듯함) / correct(정답). causal masking ⇒ cue 위치 활성값
  조건 간 비트 동일(추출 1회 공유, Figure 1). 문구 변형(의뢰의/동료/환자) ▢.
  정답지 정의: moved = 의심 병명 채택(별칭 인지, none 조건은 비언급) OR
  정답 상실 — 조건 비교로만 생성되며 모든 신호에 비공개.
- **3.3 계기 — NLA와 v2 판독 어댑터**: 공개 체크포인트(gemma-3-12b, L32,
  AV) + LoRA 판독 어댑터(구조화 XML: `<answer>`+`<supporting_cues>`, 진단
  내 케이스 분할 학습). **검증 배터리 설계**(수치는 Results 4.1): 형식·
  정밀도·heldout·셔플 대조·스왑 추적·암기·특이성·unseen.
- **3.4 비교 채널과 채점**: 체인 특징(인용/언급/천착 + 태도 분류 ▢) ·
  출력 기반(답=의심, 답 길이) · **49-way 선형 프로브(진단 내 2-fold
  교차적합 — 자기 환자 미노출)** · lens/likelihood ▢ · 판독 특징 5종(언급
  2, 불일치 2, 짝지음 상한 1) + 근거 슬롯("왜") 2종 ▢. 전 신호 단일 실행
  조건. AUROC는 진단 내 층화(라벨 결정성 교란 차단), 본선은 침묵 부분집합
  (답≠의심, 1,608 중 밀림 217 — 출력 기반이 구조적 장님). 사전 판정선
  0.60, 다중비교 개수 공개.
- **3.5 실험 설계 3종**:
  (a) **궤적**: 프롬프트 골격 랜드마크 6위치(마지막 소견→소견서→지시문
  3→최종), 랜드마크별 교차적합 프로브 곡선 + 플립 분포 + 플립 구간 판독
  서술 ▢.
  (b) **교정 사다리**: r1 직답 / r2 CoT ▢ / r3 재고 / r4 소견 재제시(통제)
  / r5 판독 되먹임 — 단마다 한 요소 추가, 소견서는 전 단 유지. 정책 비교:
  전량 개입·플래그 선별·결론 교체·하이브리드(probe 선별 × 판독 내용) ▢.
  (c) **판정자 채점**: 태도 분류·거짓 기각률·매칭 2차 ▢.
- 마지막 문단 — 계산 환경: gemma-3-12b, 4×GPU, 추출은 프롬프트당 forward
  1회 공유. 코드·시드 공개.

## 4. Results (소절마다 주장 한 문장이 제목)

- **4.1 판독은 계기로 신뢰할 수 있다** — Table 2, Figure 2, 인라인 오독
  실물(A/B/C). 수치: 형식 0.05→1.00, 1,557→52자, 정밀도 0.075→0.671,
  heldout 0.725→0.751, 셔플 +0.64, 스왑 0.993, 암기 0.000, 특이성 0.007.
  Li et al. 비판에 대한 답이 여기서 완성됨을 명시.
- **4.2 소견서 한 줄이 답을 움직인다 (그리고 설명은 그것을 예고하지
  않는다)** — Table 3, Figure 3. 없음 0.991 / 위약 0.934 / 오답 0.760
  (제안 고유 17.5pp = 위약의 4배) / 정답 0.932. 밀림 324/1,747 (채택 95 /
  상실 나머지). CoT는 편향을 완화(0.579→0.587)하지만 귀속은 못함(0.49–
  0.56; 전수 ▢) — "무관심이지 은폐가 아니다"; 거짓 기각 실물(결핵 케이스).
  누출 케이스 소멸(−0.8pp)로 개입의 인과성 재확인. 문구 변형 ▢.
- **4.3 앵커링의 해부: 원래 답은 살아 있고, 플립은 국소적이다** —
  **Figure 5(메인), Figure 4(대비 패널)** ▢. 이미 확보된 뼈대: cue 위치
  비트 동일(설계) · 소견서 위치 인코딩 균일(0.44) · 밀린 케이스 86%에서
  내부가 정답 보존(probe) · 발산은 결론 위치(0.84). 궤적이 이것을 곡선
  하나로 통합 ▢. "왜": 근거 슬롯 분석 ▢ + 케이스 패널의 판독 서술.
- **4.4 한 번의 실행에서 무엇이 밀림을 드러내는가 — 정직한 지도** —
  **Table 1(메인)**, Table 4는 부록. 설명문 0.50–0.53(태도 ▢) → 출력 기반
  0.66, 침묵에서 상수 → 프로브 0.9236/0.9842 (폐쇄 코퍼스의 승자 — 과제
  재해결 상한이라는 해석과 함께 정직하게) → 판독 0.7545/0.8415 (길이 교란
  0.667 통과, f1→포함 강건성 세트). 유일성: ③ unseen 서술 + "왜" + 다중
  위치 — probe는 49클래스 밖 정의 불가. ④ 오답 예측 열은 전 채널 실패
  (0.48 포함)를 데이터 성질(라벨 결정성)로 설명 — 정직 열.
- **4.5 식별에서 교정으로: 내용은 지렛대, 재실행은 증폭기** — Table 5.
  전 rung 전체 net 음수(0.814→0.42) · **항복률 45–64% vs 기저 8% — 재고
  요청이 앵커링을 6배 증폭, 소견 재제시가 최악(0.644)** · moved에서 r5
  0.627 vs r4 0.398(+22.8pp) = 내용의 유일성 실증(Yuan 반례) · 결론은
  오라클이 아니라 촉매(0.519→0.627) · 정밀도 병목 해부(허위 경보 3분해 ▢)
  · 하이브리드(probe 0.94 정밀 선별 × 판독 내용) ▢.
- **4.6 폭과 강건성** (짧게): corpus-300 ▢ · 문구 변형 ▢ · CoT 전수 ▢ ·
  v2 중복 제외 ▢ · [MCR 복제 ▢].

## 5. Conclusion (+ Discussion 통합)

- 요약 3문장: 검증된 자연어 판독을 인과 테스트베드에 올렸다 → 앵커링은
  출력의 사건이지 내부 소거가 아니다(보존된 결론, 국소화된 플립, 서술되는
  원인) → 탐지는 프로브에게, 서술과 열린 어휘는 판독에게 — 두 계기의
  분업이 배포 가능한 감사를 만든다.
- Implications: 임상의 대면 감사 인터페이스("Cracking the clinical code"의
  공백 지목과 연결); 재고 프롬프트의 위험(자기교정 실무 경고); 규제 관점
  한 줄.
- Limitations (정직 목록): 단일 백본(공개 NLA 생태계 제약) · 합성 코퍼스
  + 라벨 결정성(오답 예측 불성립, 프로브 우위의 조건) · 규칙 기반 매칭
  (판정자 병기 ▢) · 다중비교(특징 개수 공개) · 개입 1종(문구 변형으로
  보강 ▢) · 교정 정책 미완(하이브리드 ▢).
- Future work: MCR 어댑터(열린 어휘의 하중 지지 실험), 고정밀 플래그 결합,
  개입 형태 탐색, 타 도메인 이식.
