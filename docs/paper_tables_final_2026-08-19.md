# 논문 표·그림 설계 (확정) — 2026-08-19

**대전제**: 믿을 수 있는 진단 설명은 모델이 말하는 것(CoT)이 아니라 검증된
방법으로 내부에서 읽어낸 것이며, 그렇게 읽은 내부 증거가 오류의 설명·예측·
교정을 더 잘 해낸다.

**주의**: 기존 결과는 경향성 확인용 pilot으로 간주. 논문 수치는 통제·규모를
갖춰 재실행한다(표본 크기, 사전 고정, 예산 통일 — 각 표의 통제 항목 참조).

표기: ▢ = 측정 예정 · ✕ = 그 방법의 출력 공간상 불가(미실시 아님) ·
n.a. = 해당 과제에서 정의되지 않음 · — = 해당 없음
(pilot 값은 참고용으로 괄호 안에 표기)

# Table 4 — 충실성 검사 상세 (main ②열의 근거)

**메시지**: 같은 개입에 대해 CoT는 원인을 말하지 않고, 판독은 벡터를 따라간다.
**검증하는 명제**: H1.1 · H1.2 · H3.3
**막아내는 반박**: "0.993이 무슨 검사냐" / "CoT엔 엄격하고 자기 방법엔 관대한 것 아니냐"

**네 검사가 각각 배제하는 가짜 판독기**

| 검사 | 배제 대상 |
|---|---|
| ① 개입 추적 | 고장난 판독기 (벡터가 바뀌어도 무반응) |

# Table 5 — 오류 해부학 (main ④열의 실체)

**메시지**: 오답이 내부 증거 상태로 유형화되고, 유형에 맞는 처방만 효과가 있다.
**검증하는 명제**: H4.1 · H4.3
**막아내는 반박**: "유형은 너희가 임의로 그은 선 아니냐"

**(a) 유형 분포** — 내부 상태 기준의 오답 분류 (probe·CoT로는 산출 불가)

| 유형 | 조작적 정의 | 내부에서 일어난 일 | 비율 |
|---|---|---|---|
| 인지 실패 | 핵심 gold 증거가 판독 불가/왜곡 | 모델이 못 봤다 | ▢ |
| Distractor 과가중 | 증거 완비 + 내부 결론이 distractor 지향 | 잘못 무게를 줬다 | ▢ |
| 통합 실패 | 증거 완비 + 내부 결론 오답(distractor 아님) | 추론이 어긋났다 | ▢ |
| Decoding 실패 | 증거 완비 + 내부 결론 정답 + 출력 오답 | 알고도 잘못 말했다 | ▢ |

헤드라인 후보: "이 모델 오답의 X%는 필요한 증거를 내부에 모두 갖고도 틀렸다."

**(b) 유형 × 개입 flip rate** — 분류 타당성의 인과 검증

| | 증거 재주입 | Verifier 재생성 | Generic 재고 |
|---|---|---|---|
| 인지 실패 | ▢ **(예측: 낮음)** | ▢ | ▢ |
| 통합/distractor | ▢ **(예측: 높음)** | ▢ | ▢ |
| Decoding | ▢ | ▢ **(예측: 높음)** | ▢ |

**왜 이것이 검증인가**: "이 오답의 진짜 원인"에는 gold가 없다 — 사람도
모델 내부를 못 보므로 외부 판정이 불가능하다. 대신 각 유형은 **원인에 대한
주장**이고, 주장이 참이면 따라 나오는 예측이 있다: 증거가 내부에 없다면
프롬프트로 되돌려줘도 소용없어야 한다. 분류가 무의미한 라벨이라면 개입
효과는 유형에 무관하게 비슷해야 한다. **인지 실패 행의 '낮음'은 우리에게
불리한 음성 예측이라 우연히 맞기 어렵다** — 이것이 적중하면 분류가 실재하는
구분을 잡았다는 강한 증거이고, 동시에 "개선은 그냥 재시도 덕분"이라는
대안 설명도 배제된다.

**결과가 반대로 나오면**: 모든 칸이 비슷하면 "유형 분류는 예측력이 없었다"고
정직하게 보고하고, 개입 결과(Fig 4/Fig 5)만 주장한다.

**재실행 시 통제**: (i) 유형별 최소 표본 확보(셀당 50~100; 부족하면 오답
케이스 추가 수집) (ii) 유형 정의와 예측을 **개입 전에 문서로 고정**
(iii) 개입 예산(재시도 횟수·프롬프트 길이) 전 셀 통일.

**4형태 실물(옛 Fig 3)의 처리**: 전체 그림은 appendix로. 본문에는 4형태
**정의 1문단 + 2줄 인라인 실물**만 남긴다 —

```
gold: "chest pain even at rest"
  L24 → "chest pain at rest"                      [보존]
  L32 → "worse with exertion, relieved by rest"   [반전]
  ── probe: 두 경우 모두 "협심증 계열"로 동일 ──
```

이유: 완전히 빼면 "네 형태가 진짜 다른가"(특히 왜곡 vs 반전)에 근거가
없어지고, "probe는 구분 못 한다"는 주장도 넷이 실제로 다름을 보인 뒤에만
힘을 갖는다. 두 줄이면 그 최소 증거가 성립하고 지면은 절약된다.
Appendix에 4형태 전수 예시 + 왜곡 하위 유형(iliac fossa 끌개, 색상 오류)
+ layer별 대조표.
