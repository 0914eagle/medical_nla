## 2. 데이터 — 두 코퍼스의 정제와 현재 사용 상태

### 2.1 DDXPlus (주 실험대)

49진단 × 100케이스 = 4,900. 구조화된 소견(cue) 문자열이 있어 판독의 기계
채점이 가능한 유일한 코퍼스라 주 실험대로 썼습니다. 이번 주에 확정한 정제
사항:

| 정제 | 내용 | 영향 |
|---|---|---|
| 별칭 채점 | `URTI` ≠ "upper respiratory tract infection"으로 오답 처리되던 것을 49라벨 별칭 테이블로 수정. 채점에 쓴 별칭을 결과 파일에 **기록**하도록 강제 | 정확도 0.2920 → **0.3724** (참값) |
| 진단명 누출 탐지 | 가족력·과거력 문항이 진단명을 그대로 씀 ("ever had pneumonia"). 단어 경계 매칭으로 재집계 (단순 포함은 `PE`가 "as-pe-ct"에 걸려 과대) | **15.7%(768케이스)** 누출. 누출군 정확도 0.7031 vs 비누출 0.3110 |
| 라벨 결정성 발견 | 진단명만 아는 예측기의 오답 예측 AUROC **0.9327**. 진단 고정 시 어떤 판독 특징도 0.48~0.51 | **이 코퍼스에서 케이스 수준 오류 예측은 질문 자체가 성립하지 않음** (§3 D4) |
| 오답의 구조 | 오답의 90.1%가 해당 케이스 감별진단 상위 3위 안, 평균 순위 1.8 | 0.31을 "69% 오답"으로 읽으면 안 됨 — 감별까지 오고 좁히지 못하는 실패 |
| 표본추출 수정 | `--limit`이 파일 앞부분만 취해 진단 편중 표본을 만들던 것을 공용 샘플러로 교체 (7개 스크립트) | 이후 모든 수치의 표본 대표성 |

이 절 전체가 논문의 "벤치마크 특성" 절이 됩니다 — DDXPlus로 LLM을 평가하는
다른 연구에도 그대로 필요한 정보입니다.

### 2.2 MedCaseReasoning (MCR) — 정직한 현재 상태

- **완료**: 케이스 구축 파이프라인(라벨 정규화 포함 — "Scleroderma_renal_crisis"
  류 식별자 복원), 직답 베이스라인 832케이스 (strict 0.164; 자유 텍스트
  6,934라벨이라 strict가 과소집계임을 token-F1로 병기).
- **미완**: MCR용 판독 어댑터 학습, CoT 조건, 소견서 개입.
- **즉 이번 주의 확정 결과는 전부 DDXPlus입니다.** MCR은 "축2(오류 예측)를
  옮길 목적지"로 준비돼 있는 상태이고, 옮길지가 아래 §6의 결정 요청입니다.
  근거: MCR은 라벨이 6,934종이라 DDXPlus의 라벨 결정성(오답이 케이스가 아니라
  진단명으로 결정되는 문제)이 구조적으로 생기지 않습니다.

## 3. 실험의 흐름과 폐기 — 무엇이 죽었고 무엇이 남았나

8/17 계획(오답노트)을 실행하기 위한 측정을 준비하는 과정에서, 아래 다섯
작업가설이 순서대로 반증됐습니다. **각각 우리가 세웠고, 우리가 재서
죽였습니다.**

| # | 작업가설 | 반증 실험과 수치 | 남는 것 |
|---|---|---|---|
| D1 | 일반도메인 NLA는 의료 활성값을 못 읽을 것 | 무학습(바닐라) AV가 heldout 소견을 0.7247로 읽음 (우연 0.088; 어댑터 0.7506) | LoRA의 기여 재정의: 능력이 아니라 **계측성** (형식 0.05→1.00, 길이 1557자→52자, 정밀도 0.075→0.671) |
| D2 | CoT는 근거를 빠뜨릴 것 | 체인이 케이스 소견의 **92.3%**를 인용 (우연 17%) | CoT 불충실성 문헌의 의료 도메인 반례 |
| D3 | CoT는 정확도를 해칠 것 | 320케이스 짝지음, 차이 −1.9%p, p=0.4966 (다만 답 변경 17%) | 같음 |
| D4 | 판독이 오답을 예측할 것 (축2) | 진단명만으로 AUROC 0.9327 / 진단 고정 시 판독 0.48~0.51 (1,107쌍) | **DDXPlus에서 축2는 성립 불가** — 코퍼스 특성 절로 |
| D5 | CoT는 답을 움직인 편향에 침묵할 것 (Turpin 재현) | 소견서 언급률: 답을 바꾼 케이스 0.9833 vs 안 바꾼 케이스 0.9875 | **재현 실패가 곧 발견**: 침묵(누락)이 아니라 **무차별** — 전부 언급하므로 언급이 정보가 아님 (§4) |

오답노트 4분류에 대한 함의: **"missing cue"는 아닙니다** (D4 — 판독된 소견의
품질이 정답/오답과 무관). 남는 후보는 drift/decoding 계열이고, 이를 인과적으로
잡는 것이 §4의 개입입니다.

측정 인프라도 이 기간에 잡았습니다: 별칭 미기록, 표본 편중, 후보 집합 축소,
스캐폴드 지배 val loss, 단어 경계 매칭 — 전부 논문 이전에 수정.

## 4. 방향 전환 — 소견서(의뢰서) 개입

### 4.1 왜 이 설계인가

D2·D5가 죽으면서 분명해진 것: 소견을 바꾸는 개입으로는 설명의 충실성을 물을
수 없습니다 (소견은 차트에 있고, 체인은 그것을 받아쓰는 게 정상이므로).
필요한 것은 **답을 실제로 움직이면서, 설명이 그 역할을 식별해야 하는
원인**입니다. 의뢰 소견서의 의심 — 임상에서 앵커링 편향으로 알려진 실재
오류원 — 이 그 조건을 채웁니다.

케이스 하나를 **문장 하나만 다른 4개 조건**으로 복제합니다 (원래 정답이던
1,747케이스):

| 조건 | 삽입 문장 |
|---|---|
| 무소견서 | (없음) |
| 위약 | The referring note requests evaluation. |
| 오답 지목 | The referring note suspects {감별진단 2위}. |
| 정답 지목 | The referring note suspects {정답}. |

**설계 핵심**: 문장을 소견 뒤·질문 앞에 둡니다. causal attention 하에서 소견
위치 활성값이 조건 간 **비트 단위로 동일**해지므로, "증거 표현은 그대로인데
답이 바뀐다"가 가정이 아니라 설계의 귀결이 됩니다. 이것이 행동만 보는
선행연구(Turpin, Lanham)와 우리를 가르는 지점입니다.

### 4.2 확정된 결과 (직답, 진단명이 제시문에 없는 1,220케이스)

| 조건 | 정확도 | 대비 |
|---|---:|---:|
| 무소견서 | 0.9910 | — |
| 위약 | 0.9344 | −5.7%p |
| **오답 지목** | **0.7598** | **−23.1%p** |

- **제안 고유 효과 17.5%p (위약의 4배)** — 무는 것은 문장 침입이 아니라 지목된 내용
- **정답을 알려줘도 −6.0%p** — 소견서의 존재 자체가 교란
- **차트가 진단명을 이미 쓰면 제안 고유 효과 −0.8%p** — 앵커링은 증거만으로
  감별되지 않을 때만 발생. 통제로 넣은 층화가 결과가 됨
- 소견서가 답을 움직인 케이스 **324/1,747** — 이것이 "원인이 확정된 시험대"

### 4.3 같은 개입에서의 CoT

- **CoT는 이 편향을 무력화합니다**: 0.5787 → 0.5872 (효과 없음). 체인을 읽으면
  소견서를 명시적으로 기각합니다 ("likely a red herring", "likely premature").
- **그러나 체인은 원인을 식별하지 못합니다**: 밀린 324케이스를 체인 텍스트로
  골라내는 AUROC 0.49~0.56 (상수). 심지어 "소견서를 기각한다"고 쓴 케이스에서도
  답이 밀립니다 — **자기 보고가 행동과 어긋납니다.**

이 둘이 논문 가설1의 실측 근거입니다: CoT의 문제는 성능이 아니라 **설명으로서
인과 귀속이 불가능**하다는 것 (Turpin의 "누락"과 다른 "무차별").

### 4.4 판독(내부) 채널 — 진행 중

같은 귀속 질문을 판독에 묻는 중입니다. 1차 측정(L24 cue-어댑터):

- **소견서 위치**: 판독이 지목된 병명을 정확히 읽음. 단 밀린 케이스와 안 밀린
  케이스에서 **똑같이** 읽힘 (AUROC 0.4454) → **제안의 인코딩은 균일하다.**
  갈림은 저장이 아니라 통합 단계에 있다는 국소화의 절반.
- **답 직전 위치**: cue-어댑터가 이 위치를 못 읽음 (3,494행에 판독문 21종 —
  분포 밖 퇴화). **측정 불발이지 반증이 아님.** 이 위치·이 층(L32 format)에서
  학습된 v2 어댑터(1기 산출물, 옛 서버에서 복구)로 재판독 진행 중 — 이것이
  현재 열려 있는 마지막 미지수입니다.

**반증 조건을 실행 전에 문서화했습니다**: v2 판독도 두 조건에서 구분되지
않으면 귀속 주장은 접고, "인코딩 균일·통합에서 분기"라는 국소화 서술로
내려갑니다. 어느 쪽이든 논문의 표에 들어갑니다.

## 6. 결정을 요청드리는 것 — 두 가지

1. **축2(오류 예측)의 MCR 이전.** DDXPlus에서는 진단명이 오답을 결정해
  (AUROC 0.93) 케이스 수준 예측이 성립하지 않습니다. MCR(자유 텍스트
  6,934라벨)은 이 문제가 구조적으로 없고, 케이스 구축·베이스라인은 준비돼
  있습니다. 비용: 어댑터 학습 2~3일. 축1(설명)은 DDXPlus로 그대로 갑니다.
2. **주 실험을 소견서 개입으로 확정하는 것.** 8/17에 컨펌받은 오답노트→교정
  순서의 실행형입니다: 오류 4분류 중 missing cue가 아님이 실측으로 확정됐고,
  개입이 원인을 통제하므로 교정 실험(판독 되먹임 vs generic 재질의, CoT의
  1/30 비용)이 그 위에 바로 섭니다.
