# 04 — 의뢰 소견서 개입, MedCaseReasoning

**질문**: [03](03-note-intervention-ddxplus.md)의 효과가 **합성 문진이 아니라
실제 임상 산문**에서도 서는가.

**상태**: ✅ canonical no-note-eligible primary 재집계 완료 (08-25). 이 실험은 08-24의 학습셋 결함과 **무관하다** — 그 결함은
판독 어댑터([13](13-mcr-conclusion-adapter.md))에만 걸렸다.

---

## 왜 필요한가

DDXPlus는 시뮬레이터가 만든 불릿 목록이다. "이 효과는 템플릿 문장에서만
나오는 것 아닌가"라는 반론은 문구를 고쳐서가 아니라 **다른 코퍼스로** 닫는다.
MedCaseReasoning은 **출판된 증례보고 원문**이고, 진단명이 6,934종이며 대부분
한 번씩만 등장한다.

## DDXPlus와 다른 점 하나 — 오답 제안을 어디서 가져오는가

DDXPlus는 데이터셋이 랭킹된 감별진단을 준다. MCR에는 그런 필드가 없어서
**모델 자신의 혼동에서** 뽑는다(`make_mcr_hint_cases.py`: 코퍼스 전체의 direct
답에서 나타난 혼동 쌍). 그래서 두 코퍼스의 wrong arm은 **같은 정도로
그럴듯하지 않으며**, 행마다 `suggestion_source` 필드가 그것을 기록한다.
분석은 이 값으로 나눠 본다.

## 표본 — 이 숫자가 MCR 결과 전체를 규정한다

| | |
|---|---:|
| MCR 답 전체 | **12,620** |
| generation-time matcher에서 맞힌 케이스 | **1,543** |
| canonical matcher에서도 맞힌 primary | **1,452** |
| **canonical baseline eligibility rate** | **0.115** |

생성은 1,543건 위에서 돌았고, primary 분석은 그중 canonical matcher에서도
no-note 정답인 1,452건을 쓴다. DDXPlus와 **같은 조건**이다(움직였음을
보이려면 원래 맞았어야 한다). 다만 절대 난이도가 전혀 다르다:
DDXPlus 49클래스 대 MCR 6,934진단.

**본문에 이 숫자를 밝혀야 한다.** Table 1의 MCR 행은 MCR 전체가 아니라
"모델이 맞힐 수 있는 MCR"에 대한 결과다.

## Primary 결과

Generation-time source-correct 1,543건 중 canonical matcher에서도 no-note 정답인
1,452건만 primary로 쓴다. No-note 정확도는 1.0 by construction이다.

| | 소견서 없음 | 위약 | 오답 | 정답 |
|---|---:|---:|---:|---:|
| MCR (n=1,452) | **1.0000** | **.9339** | **.7066** | **.8388** |

- 오답 비용 **29.34%p**, 위약 **6.61%p**, 제안 고유 **22.73%p**,
  총 비용/위약 비용 **4.44배**
- moved **427** 중 제안 채택 **127**(29.7%), 제3 진단 **300**(70.3%)
- confusion 제안 n=789의 wrong 정확도 `.6882`, neighbour 제안 n=663은 `.7285`

## Fixed-cohort 감사값

| | 소견서 없음 | 위약 | 오답 | 정답 |
|---|---:|---:|---:|---:|
| MCR (n=1,543) | **.9410** | **.8879** | **.6721** | **.8179** |

- 오답 비용 **26.89%p**, 위약 5.31%p → 제안 고유 **21.58%p**, 삽입 대비 **5.06배**
- DDXPlus 3× larger run의 4.31배와 함께 **5.06배가 관측됐다.** 두 코퍼스는 난이도, 진단
  공간, 오답 제안 생성법이 달라 효과 크기의 우열을 인과적으로 비교하지 않는다.
  이 행이 닫는 것은 효과의 합성 데이터 한정 여부다.
- fixed-cohort moved **437건** 중 제안 채택은 **137건**, 제3 진단은 **300건**이다.
- 채택률은 moved 중 **31.4%**이고, **68.6%**는 제3 진단으로 간다.

## Table 1의 MCR 행을 읽는 법

- MCR 행은 합성 DDXPlus에서 본 `neutral < wrong` 구조가 실제 증례 텍스트에서도
  반복되는지를 보는 **행동 복제**다.
- Primary 모집단은 MCR 전체 12,620건이 아니라 canonical matcher에서도
  no-note 정답인 1,452건(11.5%)이다. 따라서 `.7066`을 MCR 전체 성능이라고
  말하지 않는다. 1,543/.6721은 fixed-cohort 감사값이다.
- DDXPlus와 MCR은 진단 공간, 난이도, 제안 생성법이 다르므로 4.44×와 4.40×의
  대소를 모델의 임상 취약성 순위로 해석하지 않는다. 공통으로 지지되는 것은
  **위약보다 오답 제안의 추가 비용이 크다**는 구조다.
- 이 행은 행동 효과만 복제한다. MCR에서 같은 내부 궤적이나 자연어 판독이
  작동한다고 증명하지 않는다.

## 제3 진단이 왜 중요한가

최근접 선행 연구는 객관식 과제라 힌트가 곧 선택지이고, 답이 제3의 선택지로
가는 경우를 각주에서 "uncommon"이라며 제외한다. **우리 데이터에서는 그 부류가
다수다.** 열린 진단 공간에서는 소견서가 감별 공간을 다시 열어 제3 진단으로
보낸다 — 과제 형식이 앵커링의 **형태**를 바꾼다는 관찰이고, 그들 프레임에서는
보이지 않는다.

## 설득의 화자 의존 (앵커링 대 아부의 분리)

같은 제안을 다른 화자가 나르면:

- **불안정화**(답이 흔들림)는 **화자 무관** — 동료 305건 대 환자 224건 moved
- **설득**(제안을 채택)은 **화자 의존** — 35.1% 대 7.6%, z=7.38
- MCR에서도: **41.2% 대 17.6%, z=5.26** (moved 자체는 z=1.75로 유의하지 않음)

이 해리가 앵커링과 아부(sycophancy)를 가른다. 아부는 화자의 권위에 반응하고,
불안정화는 그렇지 않다.
