# Medical-NLA discussion router

이 파일은 더 이상 라운드별 토의를 누적하지 않는다. 한 파일이 계속 커져 필요한
문맥만 읽기 어려워지는 문제를 막기 위해 토의를 주제별 문서로 분리했다.

- 운영 규칙과 현재 활성 주제: [`discussions/README.md`](discussions/README.md)
- 동결 결정 원장: [`discussions/DECISIONS.md`](discussions/DECISIONS.md)
- 현재 D14 OOF teacher 논의:
  [`discussions/2026-08-29-d14-oof-teacher.md`](discussions/2026-08-29-d14-oof-teacher.md)
- R1-R20 원문 보관:
  [`discussions/archive/2026-08-29-r01-r20.md`](discussions/archive/2026-08-29-r01-r20.md)

새 토의는 이 파일에 덧붙이지 말고 `discussions/YYYY-MM-DD-topic.md`로 만든다.
