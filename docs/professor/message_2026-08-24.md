# 교수님께 — 전제·가설·실험·결과 전체 정리 (2026-08-24)

처음 읽으셔도 따라오실 수 있게, 처음 전제부터 지금까지를 순서대로
정리했습니다. 각 단계의 상세 수치와 재현 명령은 마지막 절의 문서에 모두
있습니다.

---

## 1. 처음에 세웠던 전제와 가설 (8/19 설계)

처음 전제는 이것이었습니다: **의료 LLM이 진단을 낼 때, 모델이 스스로
출력하는 설명(chain-of-thought)은 믿을 만한 근거가 못 되고, 모델 내부의
활성값(신경망 중간층의 숫자 벡터)을 자연어 문장으로 바꿔 읽으면 더 나은
근거를 얻을 수 있다 — 특히 내부를 읽으면 모델이 어떤 케이스에서 틀릴지
미리 예측할 수 있을 것이다.**

이 전제 아래 13개의 세부 명제를 세웠습니다(설명 능력에 관한 것, 오류
예측에 관한 것 등). 명제 전체 목록과 각각이 이후 실험에서 살아남았는지는
`professor/hypothesis_disposition_2026-08-22.md`에 하나씩 정리되어
있습니다.

## 2. 그 전제를 시험한 실험들, 그리고 무너진 부분

**도구 만들기와 검증.** 공개된 NLA 체크포인트(활성값을 문장으로 복원하도록
학습된 도구)에 저희가 LoRA 어댑터를 학습시켜, 특정 위치의 활성값을 "이
상태가 담고 있는 임상 소견/결론"의 짧은 문장으로 출력하게 만들었습니다.
이것을 "판독"이라 부르겠습니다. 판독을 측정 도구로 믿을 수 있는지 8가지
검사를 했습니다 — 핵심 세 개만 들면: 케이스의 소견 하나를 바꾸면 판독도
따라 바뀌는가(99.3%가 따라옴 — 판독이 활성값에 실제로 의존한다는 증거),
바꿨는데도 원본을 말하는 암기가 있는가(0%), 다른 환자의 내용을 섞어
말하는가(0.7%, 우연 수준 이하). 이 검증 절차 자체가 "언어화 도구는 자기
지식으로 지어낼 수 있다"는 최신 비판(ICML 2026)에 대한 답이 됩니다.

**오류 예측 시도와 철회.** 원래 목표였던 "내부를 읽어 오답을 예측한다"를
DDXPlus(합성 진단 데이터셋, 49개 진단)에서 시험하다가 데이터의 성질
하나를 발견했습니다: 이 데이터에서는 **진단 이름만 알아도 모델이 틀릴지가
93% 예측**됩니다(어떤 진단은 원래 잘 틀리고 어떤 진단은 안 틀리기 때문).
같은 진단끼리만 비교하도록 통제하면 저희 방법을 포함한 모든 방법이 동전
던지기 수준으로 떨어졌습니다. 즉 "오류 예측"은 이 데이터에서는 물을 수
없는 질문이었고, 이 부분 가설들은 철회했습니다.

## 3. 수정한 전제

> 진단 설명에 필요한 것은 유창한 문장이 아니라 **원인의 식별** — 이 답을
> 실제로 만든 요인이 무엇인지 알아내는 것 — 이다. 모델의 말(CoT)은 이를
> 제공하지 못하고, 기존 내부 도구(분류기 등)는 식별하더라도 서술하지
> 못한다. 우리는 검증된 자연어 판독이 이 간극을 메움을 보인다.

"무엇이 틀릴까"(예측)에서 "**무엇이 이 답을 만들었나**"(원인 찾기)로
질문을 바꾼 것입니다.

## 4. 연구 질문 3개 (교수님의 설명/진단/교정 축과 1:1)

- **RQ1 (설명)**: 내부 활성값을 자연어로 읽어낸 것을 측정 도구로 믿을 수
  있는가?
- **RQ2 (진단)**: 실제 임상에서 있을 법한 외부 의견(의뢰 소견서의 의심
  진단)이 모델의 답을 바꿀 때, 그것을 — 어느 케이스에서, 내부의 어느
  지점에서, 왜 — 두 번 실행해 비교하지 않고 **한 번의 실행 내부에서**
  알아낼 수 있는가?
- **RQ3 (교정)**: 읽어낸 내부 정보를 모델에게 되돌려주면, 바뀐 답을
  원래대로 회복시킬 수 있는가?

## 5. 실험과 결과

**(1) 인과 실험대 — 외부 의견은 정말 답을 바꾸는가.**
모델이 소견서 없이 맞히던 1,747개 케이스 각각을 4가지 버전으로
만들었습니다: 원본 / "의뢰 노트가 평가를 요청함"(의견이 없는 같은 형식의 문장 —
문장을 끼워 넣는 행위 자체의 비용을 재는 대조용) /
"의뢰 노트가 {그럴듯한 오답}을 의심함" / "의뢰 노트가 {정답}을 의심함".
문장 하나 넣는 위치를 고정해서, 환자 소견 부분의 활성값은 네 버전에서
비트 단위로 동일하게 설계했습니다(증거는 그대로인데 답만 바뀐다는 것이
가정이 아니라 설계가 되도록).
결과: 오답 의견 한 줄이 정확도를 0.99에서 0.76으로 떨어뜨립니다. 의견
없는 대조 문장의 비용(−5.7%p)을 빼면 **의견 자체의 효과가 17.5%p, 대조
문장의 4배**입니다. 답이 실제로 바뀐 케이스는 324개였고, 화자를 바꿔도(동료의 말,
환자의 걱정) 효과가 유지되며, 표본을 3배로 늘려 다시 만들어도 같은
숫자가 나오고, 실제 증례 보고 데이터(MCR)에서도 같은 방향이 재현됩니다.
흥미로운 세부: 차트에 진단명이 이미 적혀 있는 케이스(가족력 등)에서는
효과가 사라집니다 — 증거가 스스로 결론을 내지 못할 때만 외부 의견이
작동한다는 뜻입니다.

**(2) 모델의 설명문은 이것을 알려주지 않는다.**
모델의 chain-of-thought는 소견서를 96% 언급합니다 — 그러나 언급 여부,
인용 여부, 언급 분량 어느 것도 "이 케이스의 답이 소견서 때문에 바뀌었는
가"를 구별하지 못합니다(구별 정확도 0.50~0.53; 0.5가 동전 던지기,
1,747개 전수에서 확인). 추론을 시키면(CoT) 피해가 4분의 1로 줄지만
(−17.7 → −4.4%p) 없어지지는 않고, 오히려 답이 바뀔 때 소견서의 의견
쪽으로 가는 비율은 늘어납니다(29%→43%) — 추론이 의견을 정당화할 지면을
주는 셈입니다. 지난 보고에서 "CoT가 개입을 무력화한다"고 말씀드렸던 것은
작은 표본의 과대평가였고, **"완화하지만 없애지 못한다"로 정정**합니다.

**(3) 내부는 알고 있다 — 이번 주말의 중심 발견.**
프롬프트를 읽어나가는 6개 지점(마지막 소견 → 소견서 문장 → 질문 →
지시문 → 마지막 토큰)에서 내부 상태를 추적했습니다. 예상과 달리, **답이
바뀐 케이스조차 내부 상태는 마지막 순간까지 정답을 가장 유력한 후보로
유지합니다**(바뀐 324건 중 74%는 끝까지 한 번도 소견서의 의견이 1위가
되지 않음). 그런데 출력된 답은 오답입니다. 즉 외부 의견은 모델의 지식을
지우는 것이 아니라, **답을 내보내는 마지막 단계에서만 이깁니다.** 자연어
판독도 같은 그림을 문장으로 보여줍니다: 정답을 잃은 케이스의 64%에서
내부 결론 문장은 여전히 정답이고("결론: 심근염, 근거: 좌측 흉통·호흡
곤란" — 출력은 다른 병명), 판독의 근거 칸에 소견서가 등장한 적은 한 번도
없습니다 — 내부는 소견서를 증거로 삼은 적이 없다는 뜻입니다.

**(4) 그래서 한 번의 실행에서 탐지가 됩니다.**
"내부 결론 문장과 실제 출력이 어긋나는가"를 신호로 쓰면, 출력만 봐서는
원리적으로 알 수 없는 구역(답이 소견서 의견과 다른 오답으로 바뀐
케이스들)에서 구별 정확도 0.84가 나옵니다. 정직하게 함께 보고할 것:
같은 활성값에 지도학습 분류기(linear probe)를 학습시키면 0.98로 더
높습니다. 다만 이것은 진단이 49개로 닫혀 있는 합성 데이터의 조건이고,
실제 증례처럼 진단 목록이 열려 있으면(수천 종, 케이스마다 고유) 분류기는
정의 자체가 되지 않습니다. 자연어 판독의 자리는 **열린 진단 공간 + 사람이
읽을 수 있는 서술**이며, 논문에서는 분류기를 경쟁자가 아니라 도구의
하나로 씁니다(아래 교정에서 실제로 그렇게 사용).

**(5) 교정 — 읽어낸 것을 되돌려주면.**
"다시 생각해 보라"고만 하면 오히려 해롭습니다: 멀쩡하던 답까지 대량으로
바뀌고, 바뀐 답의 45~64%가 하필 소견서의 의견 쪽으로 갑니다(원래 비율
8%의 6배 — 재고 요청이 외부 의견의 영향을 증폭). 반면 **판독이 읽어낸
내부 결론 문장을 보여주며 다시 물으면**, 답이 바뀌었던 케이스의 63%가
정답으로 돌아옵니다(같은 정보 없이 소견만 다시 보여준 통제 대비
+22.8%p). 분류기로 개입 대상을 고르고(정밀도 0.94) 판독 내용을 주는
조합은 전체 정확도를 0.814에서 0.915로 올립니다 — 탐지에서 교정까지
이어지는 고리가 닫혔습니다.

## 7. 여쭙는 것 하나

**MCR(실제 증례) 판독 어댑터 학습(2–3일) 진행 여부**입니다. 근거는 이번
주말에 완성되었습니다: 닫힌 진단 공간에서는 분류기가 탐지를 더 잘하지만
열린 공간에서는 분류기가 성립하지 않고, MCR에서 개입 효과는 이미 재현되어
있으며, 교정의 "내용을 되돌려주는" 경로가 열린 공간에서는 유일한
경로입니다. 이 어댑터가 논문의 실제-증례 칸들을 엽니다. 승인해 주시면
초안 집필과 병행해 바로 돌리겠습니다.
