# 8/19 설계 문서의 가설 13개 — 하나씩 처분 (2026-08-22)

기준점은 `paper_tables_final_2026-08-19.md`다. 거기 적힌 대전제와 명제
13개(H1.1~H4.4)가 8/19 시점의 공식 설계였고, 이 문서는 그 각각이 **살았는지,
어떤 실험의 어떤 수치로 죽었는지, 죽었다면 무엇으로 바뀌었는지**를 번호별로
확정한다. 표기: ✅ 확정 / ❌ 반증 / 🚫 질문 불성립 / 🔁 형태 변경 / ⏳ 진행 중
/ ▢ 미실행.

---

## 0. 8/19의 대전제 — 절반이 무너졌다

> (8/19) 믿을 수 있는 진단 설명은 모델이 말하는 것(CoT)이 아니라 검증된
> 방법으로 내부에서 읽어낸 것이며, 그렇게 읽은 내부 증거가 오류의 설명·예측·
> 교정을 더 잘 해낸다.

이 문장은 두 주장의 결합이었고 운명이 갈렸다.

**전반부 "CoT는 믿을 수 없다" — 살았다, 단 이유가 바뀌었다.**
8/19의 예상 기제는 누락(빠뜨리거나 숨긴다)이었다. 실측은 반대다: 체인은
소견의 92.3%를 받아쓰고(H1.1 참조) 답을 바꾼 소견서를 98.3% 언급한다.
믿을 수 없는 이유는 **무차별** — 원인이든 아니든 똑같이 말하므로 텍스트에서
원인을 식별할 수 없다 (귀속 AUROC 0.49~0.56). 결론 유지, 기제 교체.

**후반부 "내부 증거가 예측을 더 잘 해낸다" — DDXPlus에서 무너졌다.**
오답 예측은 진단명만으로 AUROC 0.9327이 나오는 코퍼스에서 물을 수 없는
질문이었고(§H4.2), 진단을 고정하면 내부 판독 특징이 0.48~0.51이다. "더 잘
해낸다"는 우월 주장은 **철회**하고, 예측이 아니라 **귀속**(무엇이 답을
바꿨는가)으로 질문을 교체했다 — 그것이 현재 진행 중인 마지막 실험이다.

**수정된 대전제 (현재):**

> 진단 설명에 요구되는 것은 유창함이 아니라 **인과 귀속** — 답을 만든 요인의
> 식별 — 이다. 모델의 말(CoT)은 원리적으로 이를 제공할 수 없고(무차별 +
> 반사실 접근 불가), 기존 내부 도구는 서술할 수 없으므로, 우리는 증거 표현이
> 불변인 개입 설계 위에서 자연어 활성 판독으로 이를 측정한다.

## 1. 가설 1 — "output(CoT)은 실제 판단 근거를 반영하지 않는다"

### H1.1 CoT의 근거는 인과적이지 않다 (절단·오염해도 답 유지) — ❌ 인접 반증 + ▢ 미실행

- 계획했던 Lanham식 절단 실험은 **돌리지 않았다.**
- 그러나 인접 실측이 반대 방향이다: CoT는 직답 대비 답을 **17%에서 바꾸고**
  (320케이스 짝지음), 소견서 편향을 **통째로 무력화한다** (직답 −23.1%p →
  CoT +0.9%p). 사후 장식이라면 일어날 수 없는 일이다 — **체인은 인과적으로
  유효한 계산이다.**
- 처분: 폐기. "체인이 인과적이냐"가 아니라 "체인이 자기 인과를 **보고**할 수
  있느냐"로 질문이 이동 (→ H1.2의 후속).

### H1.2 답을 바꾼 요인을 CoT는 언급하지 않는다 (힌트 주입) — ❌ 반증 → 🔁 무차별로 대체

- 실험: 소견서 개입, 답 변경 여부로 층화한 언급률 (381케이스).
- 수치: 답을 바꾼 케이스 언급률 **0.9833**, 안 바꾼 케이스 **0.9875**.
  "언급하지 않는다"는 정면으로 틀렸다.
- 대체 가설(신 가설1-2): **무차별** — 전부 언급하므로 언급이 정보가 아니다.
  귀속 AUROC 0.49~0.56. 결정적 정성 관찰: 체인이 소견서를 **기각한다고 쓴
  케이스에서도 답이 답이 바뀐다** (자기 보고 ≠ 행동). Turpin의 누락과 다른 실패
  방식이며, 누락은 탐지 가능하지만 상수는 불가능하므로 실무적으로 더 나쁘다.

### H1.3 내부 상태는 output이 못 드러내는 정보를 갖는다 (내부 신호의 오답 예측) — 🚫 그 형태로는 불성립 → 🔁 귀속으로 교체 ⏳

- 실험: 판독 특징 3종의 오답 예측 + 진단명 기준선 + 진단 내 층화.
- 수치: 판독 특징 0.43~0.47, **진단명만으로 0.9327**, 진단 고정 시
  **0.4801/0.5023/0.5136** (1,107쌍). 오답 예측은 이 코퍼스에서 라벨 통계
  문제이지 케이스 문제가 아니다.
- 대체: 측정 대상을 "오답 예측"에서 **"원인 귀속"**으로 교체 — 내부가 출력이
  못 드러내는 정보를 갖는지는 "답이 바뀐 324케이스를 내부 판독이 식별하는가"로
  묻는다. 1차: 소견서 위치 판독은 제안을 정확히 읽지만 무차별(0.4454) —
  **제안의 인코딩은 균일하다.** 답 직전 위치는 계측기 교체(v2@L32) 후 재측정
  진행 중. **이것이 전체 설계의 마지막 미지수다.**

## 2. 가설 2 — "기존 내부 도구는 탐지는 하되 서술하지 못한다"

### H2.1 탐지만 보면 probe로 충분하다 (인정 명제) — ✅ 확정

- probe 불일치 AUROC **1.0000** vs 판독 0.9282 (paired 152). 그대로 유지 —
  이 인정에서 출발해야 H2.2가 기여가 된다.

### H2.2 probe·SAE·lens는 조합적 임상 증거를 출력할 수 없다 — ✅ 확정

- 구조적 논증(출력 공간이 닫힌 라벨) + 실측: heldout 소견을 서술한 것은 판독뿐
  (0.7506; probe는 정의상 불가). 유지.

### H2.3 증거의 보존 형태(보존/왜곡/반전/부재)를 구분하지 못한다 — ⏳ 부분

- 판독 쪽 근거는 확보: 수동 라벨 60건에서 A(자구)/B(의미 보존)/C(속성 오류)
  분류 가능, heldout A+B 96.4%, C 3.6%는 전부 속성(위치·정도) 오류.
- "네 형태 인라인 실물"과 2차 채점자(κ)는 미완 — 남은 작업 목록에 있음.

## 3. 가설 3 — "검증 가능하게 설계된 자연어 판독이 격차를 메운다"

### H3.1 naive verbalization은 실패한다 — ✅ 확정 + 반전 하나

- 진단명 타깃은 분류기로 붕괴 (heldout answer_hit 0.29~0.35), 옳은 타깃도
  틀린 위치(format)에서는 전 layer 실패 (0.19~0.25). 유지.
- 반전: 그 "분류기로 붕괴한" v2 어댑터가 **답 직전 위치의 내부 결론을 읽는
  일에는 정확히 맞는 계측기**로 재기용됐다 (H1.3 후속 실험). 강등 사유가
  이 용도에는 자격이다.

### H3.2 올바른 설계는 학습에 없던 임상 증거를 읽는다 — ✅ 확정, 단 해석 수정

- heldout 읽기 0.7506 (우연 0.088). 유지.
- **수정**: 바닐라(무학습) AV도 **0.7247** — 읽기 능력은 설계가 만든 것이
  아니라 이미 있었다. 설계·LoRA의 기여는 **계측성**이다: 형식 0.0494→1.0000,
  길이 1,557자→52자, 전체출력 정밀도 0.0752→0.6707. (신 가설3-3)

### H3.3 판독은 벡터에 인과적으로 종속된다 — ✅ 확정

- counterfactual swap 추적 99.3% / 암기 0% / phantom 0.3%; 남의 cue 언급
  0.0067 (우연 0.0152). 유지.

### H3.4 판독 가능성은 층·위치에 따라 체계적으로 변한다 — ✅ 확정 (DDX)

- cue 위치 L24 정점, format 위치 전 layer 실패. MCR 확인은 미실행.

## 4. 가설 4 — "검증된 판독은 오류를 해부하고 성능을 개선한다"

### H4.1 오답은 내부 증거 상태로 유형화된다 — ❌ 반증 → 🔁 원인 통제로 대체

- 실험: 판독된 증거 품질과 정오답의 관계 (오답노트의 실행형).
- 수치: 인코딩 품질이 정오와 무관 (진단 고정 AUROC 0.48~0.51) — **"missing
  cue" 유형은 존재하지 않는다.** 오답 케이스에서도 증거는 잘 인코딩돼 있다.
- 대체: 유형화의 축을 "내부 증거 상태"에서 **"통제된 외부 원인"**으로 교체 —
  소견서 개입이 원인이 알려진 오류 324건을 생성했고, 이것이 새 해부 대상이다.

### H4.2 증거 인코딩 상태가 오답을 예측한다 (비순환) — 🚫 DDXPlus에서 불성립

- H1.3과 같은 수치. 코퍼스 판정으로 강등: **라벨이 6,934종인 MCR로 이전**을
  제안 (결정 사항). DDXPlus에서는 이 질문을 누구도 물을 수 없다 — 이 사실
  자체가 논문의 벤치마크 특성 절이 된다.

### H4.3 유형에 맞는 개입만 효과가 있다 — 🔁 전제 소멸로 재정의

- H4.1의 유형이 사라졌으므로 원형은 시험 불가. 재정의: **"소견서에 답이 바뀐
  케이스"라는 원인-확정 집단**에 대해, 판독 내용을 되먹인 재질의가 generic
  "다시 생각해봐"보다 회복을 더 시키는가. ▢ 미실행 (H1.3 후속 다음).

### H4.4 내부 감사 기반 개입이 출력 기반보다 정확도를 더 올린다 — ▢ 미실행, 기준선 확정됨

- 유지하되 기준선이 실측으로 정해졌다: **CoT가 이 편향을 완전 방어한다
  (+0.9%p), 비용 케이스당 ~2,000토큰.** 따라서 질문은 "판독 되먹임(1 forward
  pass)이 CoT의 1/30 비용으로 같은 방어를 하는가"로 구체화됐다.

## 5. 데이터셋 역할의 변경

| | 8/19 계획 | 8/22 실제 |
|---|---|---|
| DDXPlus | 정밀 계측 | 그대로 + **벤치마크 특성 절 추가** (누출 15.7%, 라벨 결정성, 감별 내 오답 90.1%) |
| MCR | 실제 임상 텍스트로 병행 검증 | 케이스·베이스라인만 완료. **축2(H4.2)의 이전 목적지**로 재배치 — 병행이 아니라 역할 분담 (결정 요청) |
| MedQA | 정확도 델타 전용 | 미착수 — 사실상 후순위로 강등 |

**13개 중 5개 생존, 1개 수정 생존, 3개 반증, 2개 불성립, 2개 재정의.**
반증·불성립 7건이 남긴 것을 조립한 것이 현재의 가설 사슬이다:

1. **가설1 (← H1.2·H1.3의 잔해)**: CoT 해석은 인과 귀속 불가 — 누락이 아니라
   무차별이며, 반사실 접근 불가라는 원리적 이유가 있다 ⇒ 내부를 봐야 한다
2. **가설2 (= H2.1~2.3 생존)**: probe/SAE는 내부는 보지만 서술 불가 ⇒ 방식을
   바꿔야 한다
3. **가설3 (= H3.1~3.4 생존 + D1 수정)**: 기존 NLA는 서술은 하되 계측 불가 ⇒
   Medical-NLA + **증거 불변 개입 설계**를 제시하고, 그 위에서 채널들을 같은
   귀속 채점표로 비교한다 (← H4.1의 대체가 만든 시험대)

교정(구 H4.3·H4.4)은 가설이 아니라 **응용 절**로 내려갔다: 귀속 실험의 결과
위에서, CoT 방어의 1/30 비용 대안으로 시험한다.
