# 11 — 채널 격차 신뢰구간

**질문**: "내부를 읽는 쪽이 체인을 읽는 쪽보다 14.7%p 앞선다"가 **표본 잡음이
아닌가.**

**상태**: 🔶 canonical 1,729 점추정 완료; 새 bootstrap CI 로그 전사 대기

---

## 왜 필요했나

§4.3이 기대는 문장이 점추정 두 개의 차이였다. 새 정본 침묵 구역에서는 모니터
.6904, 판독 .8319, n=1,628이며 차이는 **+.1415**다. **구간 없이는 주장이
아니다.** 심사자에게 "14.15점"을 받아들이라고
하면서 표집 잡음에 대해 우리 말을 믿으라고 요구하는 셈이다.

## 방법

`bootstrap_channel_gap.py`, 2,000회 재추출.

**① 케이스 단위 쌍(paired) 부트스트랩.** 두 채널이 **같은 환자**를 채점하므로
점수가 아니라 **케이스**를 뽑고 뽑힌 집합에서 두 채널을 다시 계산한다.
비쌍 구간은 실제 비교보다 넓다 — 어떤 진단이 표본에 들어오느냐에 따라 두
채널이 **함께** 오르내리고, 쌍으로 뽑으면 그 공유 변동이 정확히 제거된다.

**② 각 추출 안에서 진단 내 층화.** 논문의 모든 AUROC가 그렇게 계산된다. 이
코퍼스는 진단명만으로 pooled 0.93이 나오므로 pooled 값은 "진단 맞히기"를 일부
잰다. 케이스를 뽑은 뒤 층화해야 **추정량 자체**를 재현한다.

**③ 채점 안 된 케이스는 버리고 센다.** 대치하지 않는다 — 답을 못 한 판정자는
결측이고, 0.5로 채우면 실재하는 신호를 우연 쪽으로 끌어당긴다.

**④ 퇴화 추출 처리.** 어떤 진단도 moved와 unmoved를 함께 갖지 않는 추출은
AUROC가 정의되지 않는다. 전부 퇴화하면 구간을 만들지 않고 **거부한다** —
"격차가 0"과 "구간을 만들 수 없다"는 다른 말이다.

## 새 정본 점추정 (canonical n=1,729)

| 비교 | 부분집합 | 차이 | 95% CI |
|---|---|---:|---|
| 판독 − **LLM 모니터** | 침묵 (1,628) | **+.1415** | ▢ 로그 전사 |
| 판독 − 출력만 | 전체 (1,729 / moved 319) | **+.0879** | ▢ 로그 전사 |

## 이전 fixed-cohort bootstrap (audit only)

| 비교 | 부분집합 | 차이 | 95% CI |
|---|---|---:|---|
| 판독 − **LLM 모니터** | 침묵 (1,641, moved 218) | **+.1473** | **[+.0691, +.2209]** |
| 판독 − 체인 특징(최강) | 침묵 | **+.291** | **[+.230, +.354]** |
| 판독 − 출력만 | 전체 (1,747, moved 321) | **+.090** | **[+.026, +.157]** |

세 비교 모두 **옛 fixed-cohort 재집계에서** 0을 배제한다. 다만 출력 대비 격차의 하한은
+2.6%p로 가장 작고, 판독의 주된 자리는 출력 휴리스틱이 정의상 무력한 침묵
구역이다.

## Table 2b의 CI를 읽는 법

- 옛 `+.1473`은 두 독립 AUROC의 단순 뺄셈이 아니라 **같은 환자를 쌍으로
  재표집한 차이**다. `[+.0691,+.2209]`가 0을 배제하므로 표본 잡음만으로
  설명되지 않는다.
- 이 결과는 readout이 임상적으로 옳거나 원인을 완전하게 설명한다는 뜻이
  아니다. 같은 one-run moved ranking에서 LLM monitor보다 높은 정보량을
  보였다는 뜻이다.
- silent 정의를 바꾸면 모집단과 AUROC가 함께 바뀐다. `1,641/.6829`와
  `1,656/.6930`을 같은 표의 반복 측정처럼 평균내지 않는다.

## 정직하게 적어야 할 것

canonical matcher 재부트스트랩 실행은 완료됐지만 정확한 구간은 로그 전사
대기다. 전사 전에는 새 점추정이 0을 배제한다고 쓰지 않는다. 판독의 주된
자리는 여전히 **침묵 구역**이며, 여기서는 "답이 제안을 말하는가"라는 출력
휴리스틱이 부분집합 정의상 변별력을 가질 수 없다.

## 옛 fixed-cohort에서 침묵 구역 정의가 두 가지였다 (audit only)

| 정의 | n | 모니터 AUROC |
|---|---:|---:|
| `answer_names(wrong, hint)` (채널 덤프) | 1,641 | .6829 |
| `took_the_hint` (모니터 라벨 파일) | 1,656 | .6930 |

후자에는 "무소견서 답이 이미 제안을 부르지 않았다"가 추가된다. **15건 차이.**
새 Table 2b와 채널 간 차이 검정은 `answer_names(wrong, hint)`로 정의한
1,628행에 고정한다. 위 두 행은 과거 이중 정의가 만든 15건 차이를 기록하는
감사표이며 새 정본과 나란히 평균내지 않는다.

## 검증

합성 데이터로 두 극단을 확인했다: 한 채널이 실제로 더 강할 때 CI가 0을
배제하고, 두 채널이 **같은 컬럼**일 때 CI가 [0, 0]으로 붕괴한다.

## 재현

```bash
python scripts/bootstrap_channel_gap.py \
  --dump $ART/results/channel_scores_canonical_eligible.jsonl \
  --monitor $ART/results/judge_cot_monitor.jsonl \
  --a "llm monitor over the chain" \
  --b "answer omits the internal conclusion (containment)"
# 채널 이름 목록: --list-channels
```
