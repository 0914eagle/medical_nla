# 정독 노트 — When Truth Is Overridden (2508.02087, AAAI 2026)

Wang, Li, Yang, Zhang, Wang (KAUST PRADA Lab). 본문 8p + 참고문헌.
2026-08-25 전문 정독. **우리 4.3절의 위치를 정하는 논문.**

---

## 1. 그들이 한 것

**과제**: MMLU 4지선다. 프롬프트 앞에 "I believe the right answer is B"를
붙이는데 B는 **항상 오답**. 응답은 대문자 한 글자만.
**모델**: 7개 계열 ~7B (Llama3.1-8B-It, Qwen2.5-7B-It, Mistral-7B, OPT-6.7B,
Falcon-7B, OLMoE-1B-7B, Pythia-6.9B).
**조건**: Plain / Opinion-only / Opinion+Expertise(Beginner·Intermediate·
Advanced, 1인칭) / Third-pov(3인칭 Advanced).

**주요 실측**
- 시코펀시율 평균 **63.7%** (46.6–95.1%). 정확도 예: Qwen 71.3 → 44.5.
- 전문성 주장은 **영향 없음**.
- 1인칭 > 3인칭, 평균 **+13.6%p**.

**기전 도구 세 가지**
1. **Decision Score** — logit lens로 각 층에서 A/B/C/D 로짓을 뽑아
   정규화. Llama에서 1–10층은 두 조건이 유사, **16–19층에서 갈라지고
   ~19층이 전환점**.
2. **층별 KL divergence** (Plain vs Opinion의 logit-lens 출력분포) —
   초·중반 무시할 수준, **최종층에서 급등**(Llama ~23층 정점). Decision
   Score(19층)보다 **늦게** 온다 → 2단계: 출력 선호 편향이 먼저, 표상
   재정렬이 나중.
3. **Activation patching** (KL 정점 = critical layer; Llama L32 / Qwen L27)
   — Plain→Opinion 패칭: 시코펀시 0.49→**0.13**, 정확도 0.41→**0.61**.
   역방향도 성립. **양방향 인과 통제 확인.**

**전문성이 안 먹히는 이유**: 층 32 프롬프트 토큰 은닉상태 PCA에서 세
전문성 수준이 **한 덩어리로 겹침**(코사인 0.903–0.997), Opinion-only만
분리(−0.955 ~ −0.998). → "모델이 권위를 내부에 인코딩하지 않는다."

## 2. ⚠️ 우리 발견과 정면으로 부딪히는 문장

> "opinion framing alters the model's internal processing in mid-late
> layers: rather than starting with model's learned knowledge, **the model
> never establishes a strong preference for the correct answer when user
> opinion is present.** This suggests that opinion cues **prevent the
> emergence of fact-based preferences** that would otherwise develop in
> Plain conditions." (p5)

**그들**: 의견이 있으면 정답 선호가 **애초에 형성되지 않는다.**
**우리의 canonical 결과**: moved 321건 중 제안이 어느 관측 지점에서도
top-1이 아닌 경우가 266건(82.9%)이다. 그러나 정답이 모든 지점에서 top-1인
경우는 151건(47.0%)이고, 115건은 다른 진단이 top-1이다. 따라서 우리 결과는
“정답 선호가 대부분 끝까지 유지된다”가 아니라 **출력 이동이 제안 진단의
내부 top-1 우세 없이도 일어난다**는 것을 보인다.

두 진술은 그대로 놓으면 양립하지 않는다.

## 3. 그런데 계기가 다르다 — 그리고 그 차이가 정확히 우리 기여다

| | 그들 | 우리 |
|---|---|---|
| 읽는 도구 | **logit lens** (unembedding 경유) | **학습된 선형 프로브** |
| 축 | **레이어** | **프롬프트 위치**(마지막 소견→소견서→지시문→마지막 토큰) |
| 재는 것 | 출력 헤드가 지금 무엇을 내놓을까 | 표상에 무엇이 선형으로 존재하는가 |
| 대조 | Plain vs Opinion (조건 간) | 같은 케이스의 무소견서 짝 (짝지음) |

**logit lens는 출력 경로를 읽는다. 학습된 프로브는 표상을 읽는다.**
이 둘이 갈리는 것은 알려진 현상이고, **그 간극이 곧 우리가 말하는
결렬(rift)이다.**

그러므로 정확한 관계는 반박이 아니라 **분해**다:

> 그들이 "정답 선호가 형성되지 않는다"고 관측한 출력 경로와, 우리가
> 관측한 선형 디코드 상태는 같은 대상이 아니다. 우리 데이터에서는 제안이
> 내부 top-1이 되지 않고도 답이 바뀌는 경우가 많다. 일부(151/321)에서는
> 정답이 계속 top-1이지만, 이를 전체 moved 집단의 비소거로 일반화하지 않는다.

그들의 제목이 이미 "overridden"(덮어씌워짐)이지 "erased"가 아니라는 점도
이 독해를 지지한다. 다만 본문 해석("prevent the emergence")은 소거 쪽으로
기울어 있고, **그들의 계기로는 두 경우를 구별할 수 없다** — logit lens가
못 읽는 것과 표상에 없는 것을 가르려면 표상을 직접 읽는 도구가 필요하다.

**우리가 가진 증거의 범위**: 일부 행동 그룹에서 출력 정답률과 probe가
디코드한 gold probability가 크게 갈린다. 다만 canonical 그룹별 정확한
확률을 Table 3에 옮기기 전에는 과거 `.012/.959`를 대표값으로 인용하지 않는다.

## 4. 정직하게 남겨둘 차이 (반박했다고 쓰면 안 되는 이유)

- **과제가 다르다**: 4지선다 vs 열린 진단. 선택지 4개짜리 과제에서는
  오답 하나를 지목하는 것만으로 확률질량이 크게 이동한다.
- **개입 강도가 다르다**: 그들 시코펀시율 63.7% vs 우리 제안 채택 5.4%
  (답 바뀜 18.5%). 훨씬 강한 조작이므로 **정말로 더 억압할 수 있다.**
- **모델이 다르다**: Llama/Qwen/OPT 등 vs gemma-3-12b.

따라서 논문에서의 표현은 "그들이 틀렸다"가 아니라 **"그들의 관측을 표상
수준에서 분해하면 override의 정체가 미표면화임이 드러난다 — 적어도 의료
진단 과제와 gemma 백본에서는"**이어야 한다.

## 5. 이 논문이 우리에게 주는 것 (긍정)

1. **선행이 존재한다 = 현상이 견고하다.** 7개 모델 계열에서 재현된 일반
   현상의 **의료판**을 우리가 하는 것이므로, "합성 데이터의 우연"이라는
   반론이 한 겹 더 막힌다.
2. **인과 패칭이 이미 되어 있다.** 우리는 activation patching을 하지
   않았는데, 그들이 후기층 표상이 인과적으로 시코펀시를 만든다는 것을
   양방향으로 보였다. 우리 인과 주장(비트 동일 설계)과 **다른 종류의
   인과 증거**라서 인용으로 상호 보강된다.
3. **권위 논쟁이 정리된다.** 그들이 부정한 것은 **같은 화자가 주장하는
   전문성 수준**(Beginner/Intermediate/Advanced)이다. 우리가 바꾼 것은
   **화자의 역할**(의뢰 의사/동료/환자)이다. 다른 조작이므로 충돌이
   아니다. 게다가 그들 자신이 1인칭 vs 3인칭에서 13.6%p 차이를 보고했으니
   **"틀(framing)은 먹히고 주장된 자격증은 안 먹힌다"**가 그들 결론이고,
   우리 화자 역할 기울기는 그 연장선이다. → 이전 문서의 "긴장" 표기는
   **철회**하고 "보완 관계"로 고친다.

같은 형식으로 그리고, 그 위에 학습된 프로브 곡선을 겹친다. 두 곡선이
갈라지면 "override = 미표면화"가 한 그림으로 증명된다.
